# Dev.Hub

A Next.js 14 visual starter for the Dev.Hub creator/developer platform. It uses a deep navy and purple animated design, a custom cursor, project cards, channels, video showcase, downloads directory and a gold Premium concept.

## Run locally
1. Install Node.js 20 or newer.
2. Extract this ZIP and open a terminal in the `devhub` folder.
3. Run `npm install` then `npm run dev`.
4. Open http://localhost:3000.

## Deploy to Vercel
Push the extracted project to GitHub, import that repository in Vercel, and deploy. Set Root Directory to the folder containing `package.json` (leave blank if it is the repository root). No Supabase project or Supabase environment variables are required.

## Important implementation status
This is a front-end prototype with demo content. It does not currently include a persistent database or production account system. Sign-in, persistent posts, uploads, view counts, comments, follows, Discord OAuth, verified Premium checkout, and owner-only badge management need a backend and secure server-side integrations. No Supabase dependency or setup is included.
